# 實驗：從老師原有的學習單抽出「版型」，再照版型為新課產生學習單

日期：2026-11-16。模型：國網中心 `gemma-4-31B-it`（json_schema 結構化輸出）。腳本：`research/worksheet-template/`。

## 目的

老師希望上傳自己做過的學習單，讓 AI 學它的設計（區塊順序、題型、指示語、鷹架），再對新的一課很快產出一份相似的學習單。這和規格 §11 一致：從教師的學習單萃取設計規則，加上少量範例，不做訓練或微調。

這次要回答兩個問題：

1. gemma 能不能穩定抽出完整、可套用到別課、而且去識別的版型？
2. 照版型為新課文產生的學習單，像不像原本那位老師的設計？

## 材料

- **10 份範例學習單**：取自研究團隊提供的學習單資料夾，DOCX 和 PDF 各半。類型包括課文深度閱讀（TASK 1–5）、逐段提問單、段落寫作分析、句型、字彙、補充細節練習，其中兩組是同一位老師不同課的學習單。
  - 文字用平台自己的抽取器讀出，和老師上傳後系統看到的一樣：表格會攤平，順序偶爾錯亂。
  - 範例本身和抽出的版型都不進 repo，因為有著作權，部分也含教師姓名。
- **新課文**：`docs/llm-eval/worksheet-real/passages.md` 的三篇原創文章（habits、market、heat）。
- **標準答案**：人工逐份列出每份學習單的主要區塊。

## 結果一：抽版型

每份抽兩次，溫度分別是 0.2 和 0.5。「完整」指區塊和人工標準答案一致，沒有漏掉後半段。

| 版本 | 做法 | 完整 | 失控（輸出大量空白） |
|---|---|---|---|
| v1 | 一次呼叫抽出全部 | 11/20 | 3/20 |
| v2 | 同一次呼叫，schema 先列大綱再寫細節 | 大綱 20/20，細節 12/20 | 0/20 |
| v3 | 兩次呼叫：先大綱，再依大綱數量（固定 minItems/maxItems）寫細節 | 18/20 | 2/20（同一份最長的學習單，重試也失敗） |
| **v4** | 同 v3，大綱每項標 `per_paragraph`；子步驟不另列；逐段重複的區塊只列一次 | **20/20** | 2/20，重試一次（改溫度）都成功 |

- **v1 的主要問題是漏掉後半段**：「TASK 1–5」只抽到 TASK 1–2，八個區塊只抽到四個。
- **v3 的問題**：失控是因為大綱把子步驟也列進來，第二步被迫寫 11 個區塊。另外，逐段重複的區塊被攤開（一份「逐段提問單」變成 14 個區塊），換到段落數不同的課文就套不上。
- **去識別**：v4 的 10 份版型都沒有出現原課文的專有名詞、人名、學校或出版社，只剩一般教學用字。
- **時間**：每份大約 15–25 秒，兩次呼叫。

## 結果二：照版型產生新課的學習單

用 10 份 v4 版型配上三篇新課文。

| 做法 | 成功 | 備註 |
|---|---|---|
| 一次呼叫產生整份 | 6/10 | 4 份輸出太長失控，重試也失敗 |
| **每個區塊一次呼叫**（逐段區塊依新課文段數展開） | **10/10**（115 個區塊中 2 個失敗） | 每份 18–100 秒，逐一呼叫；可平行化 |

**做得好的地方**
- 區塊順序、題型、指示語語氣和鷹架都照原學習單。例如字彙學習單照樣是「拆音節 → 詞性 → 同反義 → 搭配詞中翻英 → 引導翻譯 → 自評互評 → 挑戰翻譯」，深度閱讀學習單照樣是「TASK 1 Becoming an Active Reader … TASK 5」。
- 題目都根據新課文出題。舊課文的內容沒有混進新學習單，比對 0 次。
- 逐段區塊會依新課文的段數展開。

**問題（正式功能要處理）**
1. **逐段標錯會過度展開**：例如把「B.1–B.3 各談一個面向」標成逐段，學習單就膨脹到 28 個區塊。版型需要老師確認，並設展開上限。
2. **捏造外部素材**：原學習單有「看影片後比較主題」，新學習單就編了一支不存在的影片名稱。凡是需要課文以外素材的區塊，應標成「需要老師提供」，不能自己生成。
3. **語言知識類題目會出錯**：例如音節拆分 dra-ma-tic（應為 dra-mat-ic）。要接上既有的自動檢查，或在教師版標示「請核對」。
4. **作答方式偏向填空題**：標籤只能用規格的固定選項，有些題型落到最接近的「填空題」。可接受，但版型檢視時要讓老師改。

## 結論與正式功能的做法

gemma 做得到，但要照 v4 的做法拆步驟：

1. **抽版型**：兩次呼叫（結構化大綱，再寫固定數量的細節），失控時改溫度重試一次。
2. **老師確認版型**：可以刪除、調整順序、切換「逐段」、修改作答方式。存成「我的版型」，放在教材／備課庫，之後可重複使用。
3. **產生**：每個區塊一次呼叫，平行 2–3 個，目標 30 秒內。輸出接到既有學習單的區塊結構，沿用詞彙級別檢查、依據檢查與匯出。
4. **規則**：需要外部素材的區塊只留空位和提示；逐段展開設上限。
5. **延伸**：同一套流程可以對 276 份學習單批次抽版型，再彙整成平台預設版型與設計規則，也就是規格 §11 的「結構化設計規則＋少量代表性範例」。
