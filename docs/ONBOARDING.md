# 初次使用設定與備課菜單（設計提案，待主持人確認）

> 依據：[TEACHER_NEEDS.md](TEACHER_NEEDS.md)（9 份備課問卷）、規格 v1.0 §4、§5.4（鷹架紀錄）、§6.4（完成規則）。
> 狀態：**提案**。主持人確認第 6 節的決策後才實作。

## 1. 為什麼要做

問卷顯示教師的備課起點與困難點差異很大：

- **起點不同**：有人從課文開始（T1、T2、T4），有人從學習目標或學生欠缺的能力開始（T5），有人從學生最近卡住的地方開始（T6），有人先找與學生生活相關的議題（T7），也有人先發想活動（T8）。
- **困難點不同**：新手多卡在學習目標與考點（T6、T7）；資深教師多卡在差異化與時間安排（T1、T4）；也有人卡在找程度合適的素材（T3）或與 AI 溝通（T1、T3）。

一套固定順序、固定展開所有輔助的介面，對每位教師都會有不需要的負擔。因此讓教師在初次使用時說明自己的備課傾向，平台據此調整**入口與預設展開的輔助**；規格要求的流程、紀錄與 AI 規則不變。

## 2. 初次使用設定

- 第一次登入後出現，約 3 分鐘；**可略過**（略過則用預設值），之後可在「我的備課偏好」隨時修改。
- 題目文字放後台、有版本（同 CoRe 題目的做法）。

| ID | 題目 | 選項 | 用途 |
|---|---|---|---|
| P1 | 教學年資 | 0–2 年／3–9 年／10 年以上 | 分析用；只分級避免可辨識 |
| P2 | 你通常從哪裡開始備課？ | 課文或教材／學習目標／學生的問題／活動點子 | 決定預設備課菜單 |
| P3 | 哪些步驟最花時間或最困難？（可複選） | 學習目標／找合適素材／差異化與時間安排／設計活動／學習單與評量／跟 AI 溝通 | 決定預設展開哪些輔助 |
| P4 | 你使用 AI 備課的經驗 | 沒用過／偶爾／常用 | 調整協助說明的詳細程度 |
| P5 | AI 建議希望多詳細？ | 精簡／適中／詳細 | 調整建議長度 |
| P6 | 我的班級特性（選填） | 自由文字，提示「不要寫學生姓名或個人資料」 | 單元預設班級描述，所有 AI 呼叫自動帶入 |

## 3. 四種備課菜單

依 P2 決定建立單元後的**第一個畫面**。四種菜單最後都完成同一份單元前 CoRe 與同樣結構的教案；差別只在進入順序。教師可在單元頁隨時切換。

| 菜單 | 對應 P2 | 流程 | 對應的規格功能 |
|---|---|---|---|
| 目標優先 | 學習目標 | CoRe（Q1–Q3 先）→ 課例教案 → RAG 建議 | 4.1 → 4.2 |
| 教材優先 | 課文或教材 | 貼上課文或教材文字 → 按「請 AI 從教材提供例子」取得 3–5 個候選重點（附段落）→ CoRe → 教案 | 4.5 最小版（手動貼文字） |
| 學生優先 | 學生的問題 | 班級特性與學生卡點 → CoRe Q5（學生可能怎麼想或誤解）、Q6 → 教案活動 | 4.1 Q5/Q6 → 4.2 |
| 活動優先 | 活動點子 | 先寫活動點子與教案步驟 → 回頭連結 CoRe 重點（1–3 個）→ 補 CoRe | 4.2 → 4.1 |

## 4. 偏好如何調整介面（問卷提出的 5 項修改）

| 偏好 | 調整 | 對應需求 |
|---|---|---|
| P3 含「差異化與時間安排」 | 教案步驟預設顯示「預估時間」「程度較弱的支援」「程度較好的延伸」欄位；顯示步驟總時間；AI 建議同時給這三項，時間標示「AI 估計，請依班級調整」 | N2 |
| P3 含「找合適素材」 | RAG 建議面板置頂並預設展開 | N3 |
| P3 含「學習目標」 | CoRe 第二層協助的思考面向強調：選文理由、語言以外的內容目標、與課綱及考點的連結 | N1 |
| P3 含「跟 AI 溝通」 | AI 面板顯示「Manna 已帶入的資訊」（CoRe 重點、教案、班級特性、我的範例），說明不必自己寫指令 | N4 |
| P4、P5 | 建議長度（精簡＝每項兩句內）與協助說明的詳細程度 | N6 |
| P6 | 單元層級班級特性，課例沿用、可覆寫 | N4 |
| 不分偏好 | 課例可貼「我的範例」（自己的舊教案或學習單文字）作為建議的風格參考，只存在該課例 | N5 |

**不受偏好影響**（規格要求）：
- 八步流程與完成規則：留白、略過都不阻擋（§6.4）。
- AI 不代寫、不自動填欄位，由教師判斷採用／修訂／拒絕（§4.1、§5.3）。
- 所有 AI 互動、檢索、教師判斷、鷹架事件照常記錄（§5）。
- 偏好只改「預設展開」，不隱藏功能：任何輔助都能在畫面上手動打開。

## 5. 資料與紀錄

- 新資料表 `teacher_preferences`：`teacher_id`、`version_no`、`answers`（P1–P6）、`question_set_version`、`source`（onboarding／settings）、`skipped`、`created_at`。只新增版本、不覆蓋。
- `units` 新增 `prep_route`（目前菜單）與 `class_profile`；切換菜單寫入 `usage_logs`。
- `lesson_steps` 新增 `duration_min`、`support_note`、`extension_note`（可空）。
- `lessons` 新增 `my_example`（我的範例文字，可空；不進共用知識庫）。
- 鷹架：每個依偏好預設展開的輔助，在 `scaffold_events` 記 `trigger = 'preference:P3=differentiation'` 這類觸發條件；教師手動展開或收合也照常記錄。偏好對應規則寫進各鷹架的「調適與負荷規則」欄位。
- 匯出：偏好各版本、菜單切換紀錄併入研究資料匯出（§6.5）。

## 6. 需要主持人決定

| # | 問題 | 選項 | 建議 |
|---|---|---|---|
| D1 | 教師可否自選備課入口？ | (a) 可自選四種菜單 (b) 順序固定為規格的八步，偏好只決定預設展開的輔助 | 若研究設計需要一致的介入，選 (b)；若想觀察不同備課路徑，選 (a) |
| D2 | 初次設定可否略過？ | 可／不可 | 可，符合「留白不阻擋」原則 |
| D3 | P1 年資是否收集？ | 收（分級）／不收 | 收，供分析新手與資深差異 |
| D4 | 「教材優先」的 AI 候選重點是否納入 12/15 雛形？ | 納入（手動貼文字版）／延後 | 納入，工作量小且對應規格 4.5 最小範圍 |
| D5 | 「我的範例」文字的保存與刪除規則 | 比照單元教材（教師刪除即實際刪除）／一般軟刪除 | 比照單元教材 |

## 7. 實作範圍（確認後）
