## 一、所有產出共通的規則

**R1 每份產出都要寫出內容目標與語言目標。**
- 各一個為原則，最多兩個（p. 30、32）。
- 寫學生要學會什麼，不寫活動或流程（p. 30、35）。
- 用看得到表現的動詞，例如 identify、compare、summarize、describe；不用 learn、know、understand（p. 41）。
- 用學生看得懂的句子，教師可在課堂上直接唸給學生聽（p. 30、43）。

**R2 語言目標從四類中挑。**
- 書中列出的四類依序為：學術字彙；語言技能與功能（如描述、比較、預測）；語言結構或文法；語言學習策略（p. 36–37）。書中沒有排定優先順序。
- **Manna 以語言學習策略為第一優先**【團隊決定，2026-11-17】：AI 草擬語言目標時，先考慮這一課能教哪一種策略，再視需要搭配其他三類。書中提到的策略包括：
  - 讀不懂時的補救，如重讀。
  - 自我監控，如預測後再確認。
  - 讀前策略，如先看標題、連結自身經驗。
  - 語言練習策略，如反覆練說片語。
  - 同源字策略（p. 37）。這一項對母語為西班牙語等的學生較適用，對中文母語學生參考價值有限。
- 挑選時檢查這一課的文本、教師說明、學生討論、任務、評量，哪裡會用到學生還不熟的語言（p. 40）。
- 一週內的語言目標要有變化，不要每次都只寫字彙（p. 41）。策略優先也一樣：同一單元的各課仍要輪到其他三類。

**R3 寫完目標後自我檢查。**（p. 43）
- 與課綱相關，且對應這一課的核心概念。
- 可觀察、可評量，並已規劃怎麼檢核。
- 語言目標是學生還做不好的，能推進學生的學術英語，而且和主題或活動直接相關。

**R4 活動不等於語言目標。** 活動提供練習機會，語言目標需要有明確的教學步驟（p. 49、188）。產出時，語言目標要對應到學習單上至少一個教學或示範區塊。

**R5 每個任務都要有書面、分步驟的作答指示。**（p. 106–108）
- 依學生實際操作順序列出步驟。
- 需要時附一個示範或部分完成的範例（p. 107、132）。

**R6 任務要有意義。** 與學生的生活經驗或真實用途連結，不出與主題無關的機械練習（p. 49）。

### 英文課的目標對應【團隊對應】

書中建議語文課也要同時寫兩種目標；兩者重疊時，有些教師把讀寫目標列為內容目標、把聽說列為語言目標（p. 42–43）。Manna 建議的寫法：
- 內容目標：對文本內容、主題、文體或寫作手法的理解。
- 語言目標：學生為了達成內容目標而需要的語言功能、結構、字彙或策略。

**兩個目標必須相關：語言目標是用來確保學生學會內容目標的。**【團隊決定，2026-11-17】
- 書中的依據：寫語言目標前先問「學生需要懂得、用到哪些語言，才能完成這一課的內容目標」（p. 40）；兩種目標可以緊密相連，或由語言目標延伸內容（p. 42）。
- AI 草擬時先寫內容目標，再從內容目標推出語言目標；兩者要能用一句話說明關係：「學生要用［語言目標］，才能［內容目標］」。
- 例：內容目標「說明作者用哪些例子支持論點」；語言目標「用 for example、such as、this shows that 指出例子並說明它支持的論點」。
- 說不出關係的語言目標，即使本身寫得好，也不採用。

## 二、「學習目標」欄位

- **G1 欄位拆成「內容目標」與「語言目標」兩格。**（依 R1）
- **G2 教師沒有填寫時，AI 先依文本草擬一組目標，請教師採用、修改或改寫，並記錄教師的決定。**【團隊對應，與平台「教師採用／修訂／拒絕」紀錄設計一致】
- **G3 草擬的目標要通過 R3 的檢查；不合格的不要顯示給教師。**

## 三、差異化學習單（/create/tiered，原名「分層練習」）

功能名稱改為「差異化學習單」，頁面標題讀作「來做一份 差異化學習單」。【團隊決定，2026-11-17；理由：教師熟悉「差異化教學」一詞，「分層」不直觀】本節其餘的「分層」指這項功能的設計做法（對應英文 tiered），不是介面用語。

**T0 版本名稱用「基礎／一般／進階」。**【團隊決定，2026-11-17】
- 理由：一般教師一看就懂。
- 名稱容易讓 AI 把三版做成難度高低，所以由提示詞規則把關：基礎版＝支持最多，進階版＝支持最少，三版的目標與核心題相同（T1、T2）。
- 頁面上加一句說明：「三個版本目標相同，差在提示與支持的多寡。」
- 學生拿到的版本仍用 A、B、C 標示（T9）。

**T1 三個版本用同一組目標。**
- 書中不建議為不同程度另寫語言目標，而是全班共用同一目標、依程度調整預期表現（p. 42）。
- 平台做法：三版學習單頂端顯示相同的目標。

**T2 三個版本的思考層次相同，差別只在語言支持。**
- 書中指出教師常只給程度較弱的學生字面題，建議改用分級提問：思考層次不降，只簡化問句的字詞與句構（p. 191、213–214）。
- 各組任務的挑戰程度要相當（p. 190）。
- 平台做法：三版的 Bloom 分布相同，同一題在三版問的是同一件事。

**T3 支持由多到少的形式。**
- 預填較多字的克漏字 → 只給字庫 → 句型框架 → 句首 → 不給支持（p. 112、169–170、191）。
- 平台做法：基礎版的「提示」從上面的形式中選用，不用「直接給答案位置」或「改成較簡單的題目」代替。

**T4 句型框架的做法。**（p. 169–170）
1. 先寫一個能表達該語言功能（比較、因果、問題與解決等）的完整範句。
2. 把目標字詞換成空格。
3. 拿掉的字詞做成字庫。

程度越低，範句的句構越簡單（例如簡單句、比較句、含從屬子句的複雜句三級）。

**T5 轉折詞與連接詞依程度分級。**（p. 88）
同一語言功能，初階給最基本的幾個，中階再加幾個，高階再加較正式的用語。例如表達順序，初階用 first、next、then，高階加入 previously、subsequently。

**T6 預期作答依程度調整。** 初階可接受片語或不完整的句子；程度較高者要求一到兩個完整句（p. 34）。
平台做法：答案示例與評分說明分三版寫。

**T7 題目編排：共同題加分層題。**
- 全班共同完成的題目，加上各組另外完成的題目；較難的題目開放給所有學生選做（p. 54）。
- 年紀較大的學生可以在兩種以上的作業中自選（p. 170）。

**T8 基礎版改寫文本的原則。**（p. 47–49）
- 先決定學生要從文本學到什麼。
- 先具體後抽象，刪去非必要細節。
- 簡化一般字詞，但保留關鍵概念與專有名詞。
- 長句拆成短句；難字的意思直接寫在文中；同一種句型重複使用。
- 必要時補充說明，所以改寫版可能比原文長。
- 問句以疑問詞開頭，條件句先寫 if 子句。

同時要避免過度簡化：學生仍需接觸複雜句，才學得到這類語言（p. 106）。所以基礎版仍保留原文段落，改寫版作為輔助。【後半句為團隊對應】

**T9 不要讓分層變成固定的能力分組。**
- 書中指出長期按能力高低分組，對非頂層組的學生有學業與社會上的負面影響；分組應有目的、可變動（p. 164–165）。
- 平台做法【團隊對應】：學生版不印「基礎／進階」字樣，改用中性代號（如 A、B、C 版）；教師端保留分層說明。

## 四、字彙

- **V1 選字要少而關鍵。** 只選理解文本與概念必要的字（p. 76）。
- **V2 字彙分三類，三類都要考慮。**（p. 76–78）
  - 主題字彙與專門術語。
  - 一般學術字彙：跨科用語、語言功能詞（compare、summarize、support your answer）、轉折詞。這一類最常被忽略，卻最常讓學生卡住（p. 77）。平台做法：AI 檢查作答指示中的功能詞，列入字彙區或附中文提示。
  - 字根、字首、字尾。字根表是給教師參考，不是給學生背（p. 78）。
- **V3 複習要多次、多樣。** 不出抄寫字表或只查字典的作業（p. 230–231）。結尾可請學生寫含關鍵字的句子（p. 231）。

## 五、提問、鷹架與策略

- **Q1 不同層次的問題要事先規劃，寫在學習單上。**（p. 132）
- **Q2 鷹架分三類。**（p. 131–132）
  - 口語鷹架：重述、放聲思考、請學生說得更完整。
  - 程序鷹架：示範、引導練習、獨立練習；同儕合作。
  - 教學鷹架：圖表組織、完成作品範例。
- **Q3 鷹架是暫時的，要逐步撤除。**（p. 132）
  平台做法【團隊對應】：同一單元的後續學習單，支持逐步減少。
- **Q4 任務順序。** 教師示範 → 師生共同練習 → 同儕練習 → 獨立應用；學生卡住時可以回到前一步（p. 130）。完整學習單的「逐段任務」依這個順序排列。
- **Q5 學習策略。** 分認知、後設認知、語言學習三類（p. 127–128），目標是讓學生在閱讀與寫作中實際使用，不是會說出策略名稱（p. 129）。
  平台做法：基礎版提示可附策略句首，如預測、摘要、澄清、評價時的開頭語（p. 136–137）。

## 六、課堂活動（/create/activity）與教學套件

- **A1 引起動機要明確連結學生經驗與舊知。**（p. 72–74）
  學生對主題完全沒有背景時，腦力激盪幫助不大，要先用圖片、實物或短片補背景（p. 74）。
- **A2 一節課至少兩種分組方式，如全班、兩人一組（pair）、小組（group）、個人。**（p. 165–166）
  - 分組要有目的（p. 165）。
  - 兩人一組可以直接用，寫明兩人各做什麼即可。
  - 小組（三人以上）建議寫出成員角色，例如主持、記錄、計時、報告；同時寫明時間，並安排教師巡視。書中要求小組討論讓學生清楚自己的角色與責任（p. 166）；角色名稱是團隊舉例。
- **A3 聽說讀寫要整合，安排在同一節課中。**（p. 187–188）
- **A4 應用活動的形式。**（p. 187）
  完成圖表組織、解決真實問題、辯論、用新學的句型向同學說明步驟。
- **A5 活動層級的分層。**
  - 同一寫作任務，程度高的個人完成、中程度兩三人合作、初學者與教師共寫（p. 185）。
  - 資訊差活動依程度分配資訊的份量與難度（p. 192）。
  - 依程度調整產出份量（p. 213）。
- **A6 課堂活動的輸出欄位。**
  依書中教案範本的結構（p. 314–315）建議包含：目標、關鍵字彙、教材、高層次問題、背景連結、各活動的鷹架方式、分組方式、使用的語言技能、複習與評量方式。欄位名稱由團隊自訂，不照搬範本版面。

## 七、Exit ticket 與評量（完整學習單）

- **E1 Exit ticket 要對應這一課的所有內容與語言目標。**（p. 234）
- **E2 結尾複習關鍵字彙與核心概念。**（p. 231）
- **E3 可用開放句首讓學生自選完成。**（p. 232）
  如學到了什麼、還想知道什麼、還不懂什麼。
- **E4 課前與課後各做一次目標自評，各分三級。**（p. 50）
- **E5 評量調整三方向：題數、作答時間、支持程度。**（p. 238–239）

## 八、AI 自我檢核：只用學習單看得出來的項目

書末觀察量表共 30 項（p. 302–308），原本是給觀課者在課堂上評分用的。學習單產出後，AI 只檢核書面上能判斷的項目，其餘標示「需課堂觀察」，不讓 AI 猜分數。

### 可從學習單判斷

| 量表項目 | 檢核問題 |
|---|---|
| 1、2 目標 | 是否寫出內容目標與語言目標，且符合 R1、R3？語言目標是否用來支持內容目標？ |
| 3 概念適切 | 內容是否符合年級，且沒有因改寫而刪掉核心概念？ |
| 4 補充教材 | 是否有圖、表、圖表組織等輔助？ |
| 5 依程度調整 | 是否依 T1–T8 分層？ |
| 6 有意義活動 | 任務是否連結學生經驗並練習語言？ |
| 7、8 連結經驗與舊知 | 暖身是否明確連結？ |
| 9 關鍵字彙 | 是否列出並在任務中重複出現？ |
| 11 任務說明 | 是否有分步驟的書面指示？ |
| 13 學習策略 | 是否安排學生使用策略？ |
| 14 鷹架 | 是否有鷹架，且符合 Q2–Q4？ |
| 15 高層次思考 | 是否有高層次問題，且三版都有？ |
| 16 互動 | 是否設計了學生之間的討論任務？ |
| 17 分組 | 是否寫明分組方式，至少兩種？ |
| 19 母語支持 | 是否在需要處提供中文說明？ |
| 20 動手操作 | 是否有操作性的任務？ |
| 21 應用 | 是否有應用內容與語言的任務？ |
| 22 四技 | 聽說讀寫是否都有？ |
| 27、28 複習 | 是否複習字彙與概念？ |

**評分方式【團隊對應】：** 書中量表為 0–4 分。AI 檢核建議只用「符合／部分符合／未見」三級，並附理由，交給教師判斷，不產生總分。
